**Subject:** Request: Google Workspace API access for mathclub@tokyois.com

Dear IT Team,

I am writing on behalf of LOGOS, the student mathematics club, about our club
website.

When a student is approved as a club member, we would like their school email
address to be added automatically to the view permissions on our club's shared
Google Drive folder, so that access stays in step with the membership list
rather than being maintained by hand.

To do that, we would need Google Workspace API access for the club account,
`mathclub@tokyois.com` — specifically the Drive permissions scope, limited to
folders owned by that account.

To be clear about the scope of the request:

- It would apply only to the club's own Drive folders, not to any other school
  data.
- It would only add or remove view permission for verified `@tokyois.com`
  addresses of approved members.
- No student data would leave school systems.

I am happy to go through the setup with you, or to adjust the approach if there
is a method you would prefer. Please let me know if it would help to discuss
this in person.
